\section{Bibliography}
Not always required, but citing the sources used to write any document is good practice (the teacher's own material can usually be omitted). This section collects the websites, books and articles that provided ideas or information, especially for the theoretical background.

It also helps if you want to retrieve the sources later to study, or if what you wrote is questioned.

Add each source to \texttt{bibliography.bib} and cite it in the text with \verb|\autocite{key}|.
