\begin{abstract}
    The technical report that concludes a laboratory experiment communicates the aims of the work, how it was carried out and the results obtained.

    It must be written so that anyone can reproduce the experiment and compare the results.

    For this reason the report is organised, in order, into the sections that follow. Each section is described below, with suggestions on how to write it. Replace this text with a short summary of your experiment, its method and its main result.
\end{abstract}
